# CyberShield IDS - Intrusion Detection System

Ce projet présente un Système de Détection d'Intrusions (IDS) basé sur l'apprentissage automatique (Machine Learning) en utilisant l'algorithme *Random Forest* et le dataset *NSL-KDD*.

## Fonctionnalités
- Analyse comportementale du trafic réseau.
- Interface web intuitive développée avec *Flask*.
- Visualisation des performances (Matrice de confusion, Précision, Comparaison de modèles).

## Dataset et Modèle
**Note :** En raison de la taille importante des fichiers, le dossier `dataset` et le modèle entraîné (`model`) sont conservés localement.
